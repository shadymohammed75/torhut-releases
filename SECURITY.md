# Security

If you find a security problem in Torhut (for example a way to make it send files the data policy blocks,
leak an API key, or run code without your approval), please report it privately:

**Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).

Please include the Torhut version, your OS and the steps to reproduce. Don't include real API keys or
private code. You'll get an answer as soon as possible; this is a one-person student project, so please
allow a few days.

Only the latest release gets security fixes.
